# 01 Basics

## 目的

Terraform の基本ワークフローを理解する。

## やること

- Provider を設定
- Resource を1つ作成
- `terraform init`
- `terraform validate`
- `terraform plan`
- `terraform apply`
- 設定を変更
- 再度 `plan`
- `terraform destroy`

## 記録すること

- 初回 plan の内容
- 変更後 plan の内容
- Terraform が依存関係をどう扱ったか
- `terraform.tfstate` に何が保存されたか
